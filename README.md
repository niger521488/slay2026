# Pulse Award (пример сайта премии)

Мини-пример сайта премии с голосованием на Flask + SQLite.

## Структура проекта
```
app.py                 # Приложение Flask, маршруты, работа с БД
requirements.txt       # Зависимости
awards.db              # SQLite-файл (создаётся скриптом)
static/
  css/style.css        # Базовые стили
  js/main.js           # Небольшие интерактивные эффекты
templates/
  base.html            # Общий шаблон
  index.html           # Главная страница
  nominations.html     # Список номинаций и номинантов
  vote.html            # Форма голосования
  thanks.html          # Страница благодарности
  already_voted.html   # Сообщение при повторной попытке
  admin.html           # Простая админ-страница со статистикой
  403.html             # Ответ при неверном токене
```

## Создание и заполнение базы
1. Установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. Создайте БД и демо-данные:
   ```bash
   python app.py --init-db
   ```
   Файл `awards.db` появится в корне проекта. Альтернатива — `flask --app app init-db`.

## Запуск
```bash
export FLASK_SECRET="произвольная_строка"
export ADMIN_TOKEN="letmein"  # токен для /admin?token=...
python app.py --host 0.0.0.0 --port 5000
```
После запуска страницы доступны по:
- `http://localhost:5000/` — главная;
- `/nominations` — номинации;
- `/vote` — голосование;
- `/thanks` — благодарность после отправки;
- `/already-voted` — сообщение при повторном голосе;
- `/admin?token=letmein` — статистика голосов (токен задаётся переменной `ADMIN_TOKEN`).

## Логика ограничения голосов
При отправке формы сохраняются IP и cookie `voter_id`. Если БД уже содержит голос с таким IP или cookie, пользователь перенаправляется на `/already-voted` и второй голос не принимается.

## Наполнение контентом
Демо-номинации и номинанты создаются автоматически при первом запуске или через `--init-db`. Данные можно менять напрямую в БД (SQLite) или дописать свои миграции.
